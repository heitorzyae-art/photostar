PhotoStar portable mode

While this file sits next to photostar.exe, PhotoStar keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the PhotoStarData folder beside it, and writes
nothing to %APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move PhotoStar with its settings.

Delete this file to use the normal per-user folders instead: %APPDATA%\Photostar for settings
and %LOCALAPPDATA%\Photostar\Recovery for crash-recovery autosaves. If PhotoStarData can't be
written (for example on a read-only drive), PhotoStar says so and uses those folders instead.
