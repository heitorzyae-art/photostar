Yes. PhotoStar is a free, open-source creative tool. The code is licensed under MIT or Apache 2.0, your choice, and is on [GitHub](https://github.com/storytold/photocraft).

PhotoStar works offline. Its smart selection tools run on your computer, with no cloud and no account.

See [Install PhotoStar](../getting-started/install.md) to download it.
